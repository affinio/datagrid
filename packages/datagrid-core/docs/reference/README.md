# Core reference

Use this directory when you know which part of the engine you need to understand. Start with the [Core documentation guide](../README.md) for the learning path, the [API overview](../grid-api.md) for namespace orientation, and the [method reference](./api/grid-api-methods.md) for exact signatures.

## Reference areas

| Area | Use it for |
| --- | --- |
| [API](./api/README.md) | Public entrypoints, construction, signatures, and method behavior. |
| [Core modules](./modules/README.md) | How engine capabilities work, how state flows, and where Core stops. |
| [Cross-package contracts](../../../../docs/README.md) | Behavior shared by Core, adapters, and the ready-made grid application. |

The API pages answer **what can I call?** Module guides answer **what does this subsystem do, how does it participate in the engine, and what must an adapter provide?** The two views are linked but intentionally not duplicated.
